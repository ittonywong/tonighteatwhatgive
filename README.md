# 太太菜譜站（tonighteatwhatgive）

- **GitHub repo 名（必須）**：`tonighteatwhatgive`
- **建議 Pages 網址**：https://ittonywong.github.io/tonighteatwhatgive/
- **內容**：港式家常主庫 + NZ 西餐／快手 + 每日推介（1 大人＋3 小朋友）；初形 24 款菜譜 + 七日計劃
- **技術**：純靜態（HTML／CSS／JS + JSON）；材料旁註明 CD／NW／PnS／Costco／Asian
- **Base path**：每個 HTML 會自動偵測 `/tonighteatwhatgive/`（GitHub Pages project site）。若你改咗 repo 名，要同步改每個 HTML 入面嘅 `REPO="tonighteatwhatgive"`。
- **免責**：全部菜譜標「草稿・未驗證・未試煮」；油條步驟圖由總經理提供
- **部署**：請總經理自己 Upload 到 GitHub 並開 Pages；團隊無 GitHub 權限、唔會代為 push／deploy

詳見同目錄外嘅 `上載說明-太太菜譜站-tonighteatwhatgive.docx`。
